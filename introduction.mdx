Flux Operator is a Kubernetes CRD controller that manages the full lifecycle of [CNCF Flux CD](https://fluxcd.io) and the [ControlPlane enterprise distribution](https://github.com/controlplaneio-fluxcd/distribution). It eliminates the operational burden of manually bootstrapping and upgrading Flux across fleets of clusters by providing a fully declarative, automated approach to GitOps infrastructure.

## What is Flux Operator?

Flux Operator offers an alternative to the `flux bootstrap` procedure. Instead of running a one-time bootstrap command that commits Flux manifests to Git, you declare a `FluxInstance` resource and the operator continuously reconciles the desired Flux state — installing, configuring, and upgrading controllers automatically.

## Quick Start

<Steps>
  <Step title="Install the Operator">
    Deploy Flux Operator into the `flux-system` namespace using Helm:

    ```shell
    helm install flux-operator oci://ghcr.io/controlplaneio-fluxcd/charts/flux-operator \
      --namespace flux-system \
      --create-namespace
    ```
  </Step>
  <Step title="Create a FluxInstance">
    Apply a `FluxInstance` resource to install Flux controllers:

    ```yaml
    apiVersion: fluxcd.controlplane.io/v1
    kind: FluxInstance
    metadata:
      name: flux
      namespace: flux-system
    spec:
      distribution:
        version: "2.x"
        registry: "ghcr.io/fluxcd"
        artifact: "oci://ghcr.io/controlplaneio-fluxcd/flux-operator-manifests"
      components:
        - source-controller
        - kustomize-controller
        - helm-controller
        - notification-controller
      cluster:
        type: kubernetes
        size: medium
    ```
  </Step>
  <Step title="Verify Installation">
    Check the FluxReport to confirm all controllers are running:

    ```shell
    kubectl get fluxreport/flux -n flux-system -o yaml
    ```
  </Step>
  <Step title="Configure Cluster Sync">
    Add a `sync` section to your `FluxInstance` to sync from a Git repository:

    ```yaml
    spec:
      sync:
        kind: GitRepository
        url: "https://github.com/my-org/my-fleet.git"
        ref: "refs/heads/main"
        path: "clusters/my-cluster"
        pullSecret: "flux-system"
    ```
  </Step>
</Steps>

## Core Concepts

| Concept | Description |
|---|---|
| **FluxInstance** | Declares the desired Flux distribution, components, cluster settings, and sync configuration |
| **FluxReport** | Auto-generated read-only report of the Flux installation state, updated every 5 minutes |
| **ResourceSet** | Generates Kubernetes resources from a matrix of inputs for self-service deployments |
| **ResourceSetInputProvider** | Fetches dynamic inputs from GitHub, GitLab, OCI registries, and external services |
| **Flux MCP Server** | AI bridge enabling natural language interaction with GitOps pipelines |
